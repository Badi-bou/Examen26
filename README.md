# Examen26

Ce projet peut être exécuté via une image Docker déjà construite et disponible sur Docker Hub.

##  Prérequis

- Installer Docker  
- Vérifier l'installation :

```bash
docker --version
```

## Télécharger l’image Docker

```bash
docker pull meidilprog/tpamine:v1
```
## Lancer le conteneur

```bash
docker run --rm meidilprog/tpamine:v1
```
